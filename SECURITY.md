# Security Policy for Drowzy-detector

## Supported Versions

Only the latest production release receives active security patches and vulnerability mitigations.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We prioritize the security and resilience of this project. If you discover a potential vulnerability, please do **NOT** open a public GitHub issue.

Please report the issue responsibly and confidentially:

1. **Direct Email:** Send full technical details to [nandeeshnk506@gmail.com](mailto:nandeeshnk506@gmail.com) with the subject:
   `[SECURITY] Drowzy-detector Vulnerability Report`
2. **Information to Include:**
   - Detailed description of the potential attack vector and affected endpoints/modules.
   - Minimal reproduction script or Proof of Concept (PoC).
   - Proposed remediations or mitigation steps, if available.

### Response & Remediation SLA
- **Initial Acknowledgement:** Within 48 hours of report submission.
- **Triaging & Fix Development:** Within 5 business days with a confirmed severity assessment.
- **Patch Release:** Security patches will be tested, verified against the automated CI pipeline, and released prior to public disclosure.

Thank you for responsibly helping protect this project and its users!
